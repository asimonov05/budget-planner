# ADR-008: тема — локальное предпочтение браузера

**Статус:** принято.

Светлая, тёмная и системная темы, а также схемы «Лес», «Океан», «Слива» и
«Янтарь» не относятся к финансовой модели и не требуют серверного API или
миграции. Оба выбора хранятся в `localStorage`; системный режим следует за
`prefers-color-scheme`. До запуска React bootstrap устанавливает вычисленный
`data-theme` и сохранённый `data-color-scheme`, чтобы первая отрисовка сразу
использовала правильную палитру.
