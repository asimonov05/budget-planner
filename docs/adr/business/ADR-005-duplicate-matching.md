# ADR-005: совпадение не равно дублю

**Статус:** принято.

Дата, сумма и описание формируют предупреждение-кандидат. Автоматический дубль
определяется стабильным внешним ID или повтором того же подтверждённого batch с
теми же параметрами. Две одинаковые реальные покупки можно подтвердить
отдельно.
