# ADR-007: soft delete важнее физического удаления

**Статус:** принято.

Архивирование — это soft delete: запись остаётся в базе, скрывается из обычных
списков и может быть восстановлена. Счета, категории, теги, цели и кредиты с
финансовой историей архивируются, а не удаляются физически.

`DELETE` разрешён только для несвязанной записи без операций, платежей,
резервов и других зависимостей. Все мутации проверяют `version`; удаление
финансовых фактов и переводов допустимо только в открытом месяце. Финансовые
поля плана нельзя переписывать после сверки или попадания проекции в закрытый
месяц, а график архивного кредита меняется только после восстановления
кредита. Успешное физическое удаление фиксируется в audit log.
