# Принятые решения

## ADR-001: одна валюта и целые минимальные единицы

P0 использует одну выбранную до первых финансовых данных валюту. Деньги хранятся как `amount_minor INTEGER`; RUB вводится в рублях и копейках, но API и канонический перенос используют копейки. Binary float запрещен.

## ADR-002: один production-контейнер

SPA собирается Node на build-стадии, затем копируется в Python runtime. FastAPI раздает UI и API. Это уменьшает эксплуатационный контур и соответствует режиму одной SQLite-базы и одной реплики.

## ADR-003: физический backup и финансовый перенос различаются

SQLite backup предназначен для аварийного восстановления этой установки и включает локальные служебные данные. Канонический ZIP предназначен для переноса финансовой модели в пустую установку и не содержит пароль, сессии и локальные пути.

## ADR-004: неопределенность не превращается в ложную точность

План без даты учитывается в месяце, но не в дневном прогнозе. План без счета не включается в посчетный остаток. UI помечает соответствующий прогноз неполным.

## ADR-005: совпадение не равно дублю

Дата, сумма и описание формируют предупреждение-кандидат. Автоматический дубль определяется стабильным внешним ID или повтором того же подтвержденного batch с теми же параметрами. Две одинаковые реальные покупки можно подтвердить отдельно.

## ADR-006: закрытый месяц содержит факт

В сквозном прогнозе закрытый месяц дает только факт. Закрытие не переносит и не отменяет неоплаченные ожидания автоматически; такой мастер пока не реализован. Закрытие/переоткрытие сохраняются в audit log, а изменения после reopen пересчитывают последующие остатки.

## ADR-007: архив важнее физического удаления

Счета, категории, теги, цели и кредиты с финансовой историей не удаляются: они архивируются и могут быть восстановлены. `DELETE` разрешен только для несвязанной записи без операций, платежей, резервов и других зависимостей. Все мутации проверяют `version`; удаление финансовых фактов и переводов допустимо только в открытом месяце. Финансовые поля плана нельзя переписывать после сверки или попадания его проекции в закрытый месяц, а график архивного кредита доступен для изменений только после восстановления кредита. Успешное физическое удаление попадает в audit log.

## ADR-008: тема является локальным предпочтением браузера

Светлая, тёмная и системная темы, а также схемы «Лес», «Океан», «Слива» и «Янтарь» не относятся к финансовой модели и не требуют серверного API или миграции. Оба выбора хранятся в `localStorage`; системный режим следует за `prefers-color-scheme`. До запуска React bootstrap устанавливает вычисленный `data-theme` и сохранённый `data-color-scheme`, чтобы первая отрисовка сразу использовала правильную палитру.
